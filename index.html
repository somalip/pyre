Architecture

Engineered from first principles.

Hardware-Native macOS Telemetry

No heavy systeminformation wrapper. Pyre shells directly into ioreg, powermetrics, pmset, and sysctl—accurately handling Apple Silicon independent cluster clocks, encrypted swap parsing, and AppleSmartBattery fallbacks without silent zero-value failures.

# Unprivileged sensor polling + optional root powermetrics
ioreg -rn AppleSmartBattery |Die Temp, CycleCount, mAh
sysctl -n vm.swapusage |Memory pressure & encrypted swap
pmset -g therm |Real-time thermal throttling state

Paranoid P2P LAN Streaming

Stream live hardware stats to another machine over raw TCP using a custom length-prefixed JSON protocol. Includes challenge-response nonce authentication, HMAC-SHA256 message signing, optional TLS, per-IP rate limiting, and audit logs.

# Host machine (streams signed telemetry over LAN)
$ pyre p2p server --port 9440 --tls

# Client machine (verifies nonce + HMAC-SHA256)
$ pyre p2p connect 192.168.1.42:9440

Command Lifecycle Benchmarking

Wrap any build script, test suite, or compiler invocation with pyre bench to record CPU utilization, peak memory footprint, network I/O, and thermal delta for the exact lifespan of the process.

$ pyre bench "cargo build --release"
→ Duration: 14.2s | Peak CPU: 784% | Peak RSS: 1.42 GB
→ Thermal Delta: +11.4°C | Exported: bench-run.json

Multi-Surface Output & Anomaly Detection

Switch effortlessly between the full-screen terminal TUI, a native macOS floating desktop window (pyre ui), a live Server-Sent Events web dashboard (pyre web), or statistical z-score anomaly detection over historical logs.

$ pyre ui --compact --ontop # Native macOS HUD window
$ pyre web --port 8080 # Real-time SSE browser portal
$ pyre --json --once # Pipeable structured snapshot

CLI Reference & Modes

Command / Flag Surface Description
pyre live TUI Dashboard Interactive full-screen ANSI dashboard with rolling sparklines, process manager, and PID signal control.
pyre CLI Snapshot Instant single-frame hardware, thermal, memory, and network summary printed directly to stdout.
pyre check Diagnostic One-shot instant system health diagnosis in plain English with actionable bottleneck alerts.
pyre ui [--compact] [--ontop] macOS Native Launches the native macOS desktop Activity Monitor window with optional compact floating HUD mode.
pyre web SSE Web Portal Serves a zero-dependency local web telemetry portal streaming real-time metrics via Server-Sent Events.
pyre p2p server LAN Stream Starts an authenticated, HMAC-SHA256 signed TCP telemetry server for remote machine monitoring.
pyre bench <cmd> Profiler Profiles CPU%, memory, network RX/TX, and thermal sensors for the lifetime of any shell command.
pyre --json | --csv | --tsv Export Outputs structured telemetry for scripts, CI pipelines, or continuous background logging.
