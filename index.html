Pyre

System monitoring reimagined. Real-time insights into your machine.


  







  

    

      

        
Performance

        
See inside your Silicon

        
Direct register probes give you insight into CPU cluster loads, memory bandwidth, and Neural Engine states in real time. Know exactly what your machine is doing.

        

          Command:

          $ pyre live
        

      

      

    

  







  

    

      

      

        
Temperature

        
Thermals at a glance

        
SMC sensor integration gives you precise thermal readings across your machine. Watch heatpipe dissipation, fan curves, and throttling states in real time.

        

          Command:

          $ pyre check
        

      

    

  







  

    

      

        
Connectivity

        
Network socket visibility

        
Trace every connection on your machine. Link socket egress and ingress to precise process IDs, and monitor bandwidth per connection in real time.

        

          Command:

          $ pyre netusage
        

      

      

    

  







  

    

      

      

        
Energy

        
Battery and power metrics

        
Coulomb counter telemetry tracks battery health, subsystem power draw, and charge cycles. Predict runtime and identify power-hungry processes.

        

          Command:

          $ pyre bench "<command>"

Installation

    
Get Pyre in seconds

    

      Zero configuration required. Install globally via npm to monitor your machine with full telemetry.
    


    


    

      npm install -g pyre-cli
      
    

    

      Requires Node.js 18+. Run pyre live after installing.
    

    

      
    

  








  

    

      📖 Pyre Documentation
    

    
  

  

    

      Quick reference for CLI commands, live TUI controls, and telemetry features.
    


    

      
      
      
    


    
    

      

        
          

            Command
            Description
          

        
        
          

            pyre
            Instant formatted terminal snapshot of CPU, Memory, Disk, Net & Thermals
          

          

            pyre live
            Interactive full-screen TUI dashboard with real-time sparklines & bar graphs
          

          

            pyre live --interval 1 --log
            1s refresh interval with continuous CSV telemetry logging to disk
          

          

            pyre web [--port 3000]
            Browser dashboard portal powered by Server-Sent Events (SSE)
          

          

            pyre fleet <host1> <host2>
            Multi-host aggregated live dashboard over SSH / mesh network
          

          

            pyre ssh <user@host>
            Stream live stats from a remote machine securely over SSH
          

          

            pyre anomalies --since 7d
            Statistical z-score spike digest detecting runaway processes
          

          

            pyre doctor
            Audit permissions, SIP, Gatekeeper, and Apple Silicon SMC sensors
          

          

            pyre bench "<command>"
            Benchmark command CPU/RAM and compute energy consumption in kWh & Joules
          

          

            pyre info
            Deep hardware summary: CPU clusters (P/E), RAM, GPU VRAM, battery health
          

          

            pyre brew
            Package manager health check, cleanup suggestions, and disk cache report
          

          

            pyre --json
            Export telemetry as structured JSON (also --csv, --html, --md)

Mouse support is enabled by default: click tabs or scroll inside process lists.

    


    
    

      
Stream real-time hardware telemetry directly over your LAN without third-party brokers:

      
      
1. Server Host Machine:

      

        pyre p2p server --p2p-password "secret" --p2p-port 9876
        
      


      
2. Client Receiver Machine:

      

        pyre p2p connect --p2p-host <server-ip> --p2p-password "secret" --p2p-port 9876
        
      

      
Includes TLS encryption (--p2p-tls) and HMAC-SHA256 challenge authentication.
