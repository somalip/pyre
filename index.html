Pyre

System monitoring for your Mac.

Install

Four views.

Hardware-level detail, no configuration needed.

Silicon

Performance and efficiency cores, memory bandwidth, Neural Engine.

$ pyre live

Thermals

SMC temperatures, fan speeds, throttling status.

$ pyre check

Network

Per-connection forensics with socket-level detail.

$ pyre netusage

Power

Battery health, cycle count, and per-process energy.

$ pyre bench "npm test"
$ pyre live

Get Pyre.

Install once with npm. No configuration needed.

npm install -g pyre-cli

Requires Node.js 18 or later. Then run pyre live.
